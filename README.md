# shooter-shmooter
little shooter for fun :3
Hello there! This is the rules for this little game:
1. for reload, pls tap R
2. you can control the ship using the arrow keys (left-right)
3. you will lose if:
      1) touch the alien
      2) miss 10 aliens
      3) spend 3 lives
4. you will win if you kill 3 aliens
   !HAVE A NICE GAME!
